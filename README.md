# ecuador-trachoma-elimination
R scripts used to conduct analyses to support the paper: Kamau E, Simbaña L, Torres S, Walas N, Cooley G, Coleman C, et al. **Serologic assessment of public health action needed for trachoma, coastal Ecuador, 2021–2024.** _Emerg Infect Dis._ 2026. https://doi.org/10.3201/eid3211.261024

These materials are permanently archived on Zenodo: https://zenodo.org/records/22926086
